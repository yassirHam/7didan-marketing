\section{Yassir -- CRM, Automation, Integration \& Analytics}

\textbf{Main responsibility:} Own the CRM transaction pipeline, workflow automation, reporting, and end-to-end integration quality.

\subsection*{A. Odoo CRM}
\begin{itemize}
  \item Install and configure Odoo CRM.
  \item Configure the sales pipeline and opportunity stages.
  \item Define custom CRM fields for service interest, budget, timeline, and lead score.
  \item Configure lead sources and qualification status.
  \item Implement and verify opportunity creation.
\end{itemize}

\subsection*{B. n8n Workflow Automation}
\begin{itemize}
  \item Design the complete n8n workflow.
  \item Connect FastAPI to n8n through webhooks.
  \item Implement data validation and field mapping.
  \item Connect n8n to Odoo CRM.
  \item Handle duplicate submissions, API failures, and retries.
  \item Return CRM transaction status to the backend.
\end{itemize}

\subsection*{C. CRM Integration}
\begin{itemize}
  \item Integrate the qualification system with Odoo.
  \item Ensure correct mapping of structured lead information.
  \item Implement record verification after creation.
  \item Ensure idempotency and prevent duplicate opportunities.
  \item Document the integration and API communication.
\end{itemize}

\subsection*{D. Power BI Dashboard}
\begin{itemize}
  \item Design the marketing and CRM analytics dashboard.
  \item Connect Power BI to the relevant PostgreSQL and CRM reporting data.
  \item Create data models and relationships.
  \item Develop DAX measures and KPIs.
  \item Visualize the lead qualification funnel, lead sources, CRM success rates, and processing performance.
\end{itemize}

\subsection*{E. Testing and Quality Assurance}
\begin{itemize}
  \item Test the complete FastAPI $\rightarrow$ n8n $\rightarrow$ Odoo workflow.
  \item Test valid and invalid enquiries.
  \item Test duplicate submissions.
  \item Test API authentication and connectivity failures.
  \item Verify actual Odoo records.
  \item Validate Power BI figures against the underlying data.
  \item Document test results and integration limitations.
\end{itemize}

\subsubsection*{Deliverables}
\begin{itemize}
  \item Odoo CRM configuration
  \item n8n workflow export
  \item CRM integration
  \item Power BI dashboard
  \item Integration test report
\end{itemize}

\section{Amine -- AI, RAG \& Backend}

\textbf{Main responsibility:} Own knowledge retrieval, AI intelligence, backend orchestration, and AI evaluation.

\subsection*{A. Knowledge Base}
\begin{itemize}
  \item Collect official Orange Maroc Business documents.
  \item Extract and clean catalogue and FAQ information.
  \item Implement document chunking and metadata management.
  \item Prepare the knowledge base.
\end{itemize}

\subsection*{B. RAG Engine}
\begin{itemize}
  \item Implement embeddings using Sentence Transformers.
  \item Configure semantic retrieval using PostgreSQL and pgvector.
  \item Implement relevance filtering.
  \item Develop grounded answer generation.
  \item Display source references.
  \item Implement abstention for unsupported questions.
\end{itemize}

\subsection*{C. Backend and Conversation Intelligence}
\begin{itemize}
  \item Develop the FastAPI RAG endpoints.
  \item Implement conversation orchestration.
  \item Extract structured information from customer messages.
  \item Coordinate the qualification flow with the frontend and CRM backend.
\end{itemize}

\subsection*{D. AI Evaluation}
\begin{itemize}
  \item Prepare the 20-question benchmark with expected answers.
  \item Evaluate retrieval relevance and answer correctness.
  \item Test hallucinations, unsupported questions, and prompt injection.
  \item Document evaluation results.
\end{itemize}

\subsubsection*{Deliverables}
\begin{itemize}
  \item Knowledge base
  \item RAG engine
  \item AI backend
  \item Evaluation report

\section{End-to-End Collaboration Flow}

\begin{enumerate}[leftmargin=1.8em,itemsep=0.5em]
  \item Amal's frontend captures the conversation, qualification answers, contact information, and consent.
  \item Amine's FastAPI and RAG components answer supported questions, orchestrate the conversation, and produce structured lead data.
  \item Yassir's n8n workflow validates and maps the structured data before creating or updating the corresponding Odoo opportunity.
  \item The integration verifies the CRM record and returns the transaction status to the backend and customer interface.
  \item PostgreSQL and CRM reporting data feed Yassir's Power BI dashboard for funnel, source, reliability, and processing analysis.
  \item The whole team validates the deployed workflow and presents the final demonstration.
\end{enumerate}
